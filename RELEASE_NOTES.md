# Release Notes

## TaxoMatrix v0.1.1

This release extends the original ANI workflow with:

- accession-based genome downloads from NCBI assembly accessions
- cached downloaded genomes in the output directory
- citation and acknowledgement guidance for upstream tools
- clearer logging for provenance and download mode usage

The core TaxoMatrix workflow remains unchanged:

- FastANI-based all-vs-all ANI analysis
- CSV and Excel matrix export
- publication-quality clustered heatmaps in PNG, SVG, and PDF formats
- metadata-aware output labeling and logging

## TaxoMatrix v0.1.0

The `v0.1.0` tag marks the initial public release of the core ANI workflow.
